# Shards

Приложение для помощи контроля нескольких сфер жизни.

## Стек

React 19, TypeScript, Vite, FSD, ESLint, Prettier, Husky.

## Требования

- Node.js >= 22
- npm

## Установка

npm install

## Скрипты

npm run dev — dev-сервер
npm run build — production build
npm run lint — линт
npm run format — форматирование
npm run format:check — проаерка форматирования
npm run preview — превью
